# tzmatch

仪器日志只记录本地钟面。给定一个 [RFC 8536](https://www.rfc-editor.org/rfc/rfc8536.html)
TZif（版本 2/3）文件和一组钟面时间，本工具找出**每一个**满足
`UTC 整数秒 u + 该 UTC 瞬间生效的偏移 == 钟面` 的整数秒 `u`，按原序输出，
每个钟面的结果升序去重；无匹配输出 `[]`，空数组输入输出 `[]`。

不依赖任何第三方时区库：TZif 解析、受限 POSIX TZ 尾串、日历与转换全部自写，
仅使用 Python 标准库。UTC 秒自 1970-01-01T00:00:00Z 起算，按每天 86400 秒
均匀计数，**不计闰秒**。

## 目录结构

```
tzmatch/
  cal.py      公历日历运算（自写，含 Mm.w.d 的 w=5 规则）
  tzif.py     RFC 8536 TZif v2/v3 严格解析与全部字段校验
  posix.py    受限 POSIX TZ 尾串解析、规则时刻与交替校验
  engine.py   输入校验、尾串一致性、偏移查询与候选枚举
  errors.py   带零基字节 / 零基数组路径的异常类型
  cli.py      命令行入口与原子输出
  __main__.py 支持 python -m tzmatch
tzmatch_tool.py        顶层入口脚本
acceptance/
  tzif_builder.py       验收用 TZif 构造器（被测代码不依赖它）
  test_acceptance.py    独立验收套件（unittest，标准库 + zoneinfo 对照）
```

## 用法

```bash
python3 -I tzmatch_tool.py <tzif 文件> <时间 JSON> [-o 输出 JSON]
```

- 时间 JSON 是 `["YYYY-MM-DDTHH:MM:SS", ...]` 字符串数组。
- 不带 `-o` 时结果打印到标准输出；带 `-o` 时**先写临时文件、fsync、再
  `os.replace` 原子替换**，因此任何前置步骤失败都会保留旧输出文件不变。
- 建议始终用 `python3 -I` 运行：隔离模式不把脚本目录 / 当前目录放进
  `sys.path`，可防止数据目录里被植入的同名模块（如 `json.py`）被加载。

成功输出示例（任务给定用例：类型 0 偏移 +3600，UTC 秒 0 切到偏移 0，尾串空）：

```json
[[-1800,1800]]
```

## 失败报告（整次拒绝）

非法输入整次拒绝，不产生部分结果。

- 文件类错误：`{"error": ..., "byte": <零基字节>}`。报错字段起始字节即
  `byte`；文件截断时 `byte` 等于当前文件长度；多错可报任意一个。
- 时间数组类错误：`{"error": ..., "path": [<零基下标>]}`；顶层非数组用
  `path: []`。

## 实现要点与严格校验

- 32 位块只校验长度后整体跳过，权威数据来自 64 位块；两个头的版本与六项
  计数必须一致，两个 `leapcnt` 必须为 0。
- 校验魔数 / 版本（仅 2、3）、保留零字节、计数、转换时刻严格递增、转换
  类型索引范围、`ttinfo` 的 `isdst` 与缩写索引、缩写 NUL 结尾且可打印、
  两个指示位数组取值、尾串前后换行框架以及**尾换行之后无任何字节**。
- 首个转换之前用类型 0；转换瞬间起即采用新类型；无转换全程用类型 0。
- 空尾串：沿用最后一个类型（有转换）或类型 0（无转换）。
- 非空尾串仅接受：
  - 固定偏移型 `std offset`；
  - 季节型 `std offset dst[offset],start,end`，两条规则都必须是
    `Mm.w.d/time` 且 `/time` **显式给出**。名称限 3~6 个 ASCII 字母
    （拒绝尖括号名）。夏令偏移省略时按 RFC 取标准偏移 +1 小时。
  - 规则小时：v2 无符号 0~24；v3 可带符号 -167~167。`w=5` 取该月最后一个
    指定星期。起止分别按标准 / 夏令本地钟解释，支持南半球跨年。
  - 规则事件须严格交替且不同刻。
- 有转换时尾串自末转换起适用，且必须与末类型一致；无转换时全程适用并与
  类型 0（标准侧）一致，否则整次拒绝。
- 候选枚举不预设“至多两个”：对每个出现过的偏移求 `u = 钟面 - 偏移`，
  再用该 UTC 瞬间的生效偏移复核，保留全部命中并升序去重。

## 验收

```bash
python3 -I acceptance/test_acceptance.py -v
```

覆盖：日历运算与严格输入校验、任务给定重叠示例、春令跳时（空匹配）、
秋令重叠、构造出的**三候选**钟面、南半球跨年与 w=5 规则、空尾延续与无
转换文件、二进制与尾串的严格拒绝（含零基字节 / 路径）、原子输出（失败
保留旧结果）、以及限定在共同合法子集内的 zoneinfo 对照。套件还内置对
系统时区库的批量随机对照（数万探针，零偏差）。
